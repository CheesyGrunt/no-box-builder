What this process does

Every month we pull the deployed member list and figure out who did not get a box. This process takes those two reports, builds a clean No Box tab, tells you who is already waitlisted, who is waiting on an Angel to make contact, and who still needs a box shipped. The finished tab gets handed to staff for fulfillment.

The prompts do the heavy lifting. Your job is to pull the right reports, check the filters, and paste the prompts in order.

Read this first

Work the steps in order, 1 through 12. Do not work ahead and do not pull reports early. Each step depends on what the step before it produced.

Deployed Monthly Part 2 cannot be pulled until Step 4 gives you the batched Client IDs.

Before Prompt 3 in Step 8 and Prompt 5 in Step 10, replace [Current Month] with the actual month you are reporting on.

The reports and when you pull them

Do not try to gather all four reports up front. Deployed Monthly Part 2 does not exist until Step 4 hands you the batched Client IDs. Pull each report at the step listed and add it to the same workbook as you go.

The steps

1

Pull your two reports

About 5 minutes

Open Deployed Monthly Part 1.

  • Check the filters. Make sure the month matches the month you are pulling. This is the most common place to make a mistake.
  • Export the Formatted Report. Label that tab Deployed Report.
  • Export the Details Only Report. Label that tab Details.
2

Add the "Got a Box" formula

About 3 minutes

Go to the Deployed Report tab.

  • Clear columns J and K (the Fulfilled Flag and Record Count columns).
  • In J, type the header Got a Box.
  • Put this formula in J and fill it down the whole column:
=IF(H18>0,1,0)

Then build your totals underneath:

  • Sum column I
  • Sum column J
  • In K, subtract J from I
  • Below that, divide J by I to get your percentage
3

Run Prompt 1, build the No Box tab

Up to 5 minutes

Paste it in exactly as written.

Prompt 1
From the "Deployed Report" tab, build a new tab called "No Box" listing every member with a 0 in the "Got a Box" column (column J, data rows 18-6000). Not a pivot table, a plain sortable table. Do NOT bring over the Unique Client, Fulfilled Flag, or Record Count columns from the report. Set up these exact column headers (row 5), data starting row 6:

Client Name | Status | Client ID | Mail Stop Date | Service Delivery | Report by Date | Client First Name | Client Last Name | Client: Mailing Address Line 1 | Client: Mailing Address Line 2 | Client: Mailing City | Client: Mailing State/Province | Client: Mailing Zip/Postal Code

Fill in this step:

- Client Name: the no-box members, pasted as static values so I can sort/filter

- Client ID: live INDEX/MATCH from the Details tab (name in col L to "Client: Contact ID" in col K)

- Leave Status blank ("Waitlist" gets added later)

Add a maroon title banner "Members Without a Box" top-left and an AutoFilter on the header row.
4

Batch the Client IDs

Steps 4 and 5 together, about 15 minutes

Take the Client IDs and plug them into Claude to have them separated into batches of 70. You need them batched because the report filter cannot handle the full list at once.

5

Generate Deployed Monthly Part 2

Included in the 15 minutes above

Take your batches and update the filters on the report. Check your logic before you run it:

Program Engagement Name AND (All your Client IDs with or in between the numbers) AND Created Date AND Service Delivery Name
  • Export in Details form.
  • Add it to the workbook with the other tabs. Name it Deployed Monthly Part2.
6

Run Prompt 2, fill dates, names, addresses

Up to 5 minutes
Prompt 2
Fill the No Box tab's remaining columns (live formulas, matched on client name):

- Mail Stop Date, Details col H (mm/dd/yyyy)

- Service Delivery, "Yes" if a Status="Assigned" row exists in "Deployed Monthly Part2" (Client col A, Status col F)

- Report by Date, earliest Assigned Report By Date from that tab (col G; dates there are text, so convert with DATEVALUE)

- Client First/Last Name, split from the client name

- Address Line 1 / Line 2 / City / State / Zip, from "Deployment Monthly Part2" (Street J, City K, State L, Zip M), using the first row per client with a non-blank street; Zip must stay text (keep leading zeros)
7

Pull the Currently Waitlisted report

3 to 5 minutes

No filter changes needed on this one. Export it in Details Only and drop it into the workbook with the rest. Name the tab Currently Waitlisted Clients.

8

Run Prompt 3, highlights and Status column

Up to 5 minutes
Before you paste

Replace [Current Month] with the month you are actually reporting on. If you skip this, the blue highlights will be wrong.

Prompt 3
Highlight rules on the data rows, in priority order:

1. GOLD (#FFC72C, bold maroon text): member is on the 'Currently Waitlisted Clients' tab (match name against col K). Gold wins over blue.

2. BLUE (#4472C4, bold white text): Service Delivery = "Yes" AND Report by Date falls in [Current Month].

Then fill the Status column with a live formula using the same logic:

- Gold/waitlisted rows to "Waitlisted"

- Blue rows to "Needs Angel Contact"

- All other rows to "Unsupported, send Box"
Swap [Current Month] before pasting
9

Run Prompt 4, summary block

Up to 5 minutes

This adds the summary block so leadership can see the numbers at a glance.

Prompt 4
Finish the No Box tab with the summary block in E1:F4, next to the title banner, labels in E, live formulas in F:

E1 "True Count of Unsupported" F1 = COUNTIF of Got a Box = 0 on Deployed Report

E2 "Current Waitlist Count" F2 = COUNTIF of Status column = "Waitlisted"

E3 "Pending Service Delivery" F3 = COUNTIF of Status column = "Needs Angel Contact"

E4 "Total Boxes to Send" F4 = F1 - F2 - F3

Style: labels bold maroon on light maroon #F2DEDE; F2 on gold #FFC72C; counts centered, #,##0.
10

Run Prompt 5, check for errors

Up to 5 minutes

Every one of these members should have a military mail address. Anything that is not APO, FPO, or DPO gets flagged purple so you can eyeball it before shipping. This step also flags in red anyone whose Mail Stop Date falls in the month you are reporting on, so you can confirm they are still eligible before a box goes out.

Prompt 5
On the No Box tab, add a PURPLE error flag (#7030A0 fill, bold white text) on the address columns (Mailing Address Line 1 through Zip) for any row where the Mailing City is filled in but is NOT "APO", "FPO", or "DPO" (case-insensitive), those should all be military mail cities, so anything else is a potential address error.

Also add a RED flag (#C00000 fill, bold white text) across the entire data row for any row where the Mail Stop Date falls in [Current Month].

Priority order: gray empty-cell rule first, then this red current-month Mail Stop Date flag, then the purple address flag, then the gold waitlist and blue pending highlights.
Swap [Current Month] before pasting
Stop here

Look at the purple and red rows before you move on. Fix bad addresses and confirm the red current-month Mail Stop Dates now, not after the file is locked down.

11

Run Prompt 6, hard-code the tab

Up to 5 minutes

Last step before this goes to staff. This converts every formula to a plain value so the rows can be copied into other files without breaking.

Prompt 6
On the No Box tab, convert every formula to its current value (hard-code the whole tab):

- All data columns (Status, Client ID, Mail Stop Date, Service Delivery, Report by Date, First/Last Name, and all address columns)

- The summary counts in F1:F4

Keep all formatting, highlights, and number formats exactly as they are, just replace the formulas with their calculated values, so the rows can be copied and pasted into other files without breaking. Confirm afterward that no formulas remain on the tab.
12

Check the work

Up to 15 minutes

Nothing gets sent until this step is done. Open the finished No Box tab and look at it with fresh eyes. Adjust column widths, wrapped text, number formats, and the title banner. Then run down this list. If all seven are true, the file is ready for staff.

Not ready to send 0 of 7 confirmed

If something looks off

What you seeWhat is probably wrong
#N/A in Client ID or address columnsThe client name does not match between tabs, or a tab name is off. Check spelling on the tab names first.
Nobody is highlighted goldThe Currently Waitlisted Clients tab is missing or named differently.
Nobody is highlighted blueYou forgot to swap [Current Month] in Prompt 3, or Part 2 did not export right.
Nobody is highlighted redYou forgot to swap [Current Month] in Prompt 5, or the Mail Stop Date column is stored as text instead of a date.
Zip codes lost their leading zeroThe Zip column got formatted as a number. It has to stay text.
Counts in F1:F4 do not add upPrompt 3 ran before Prompt 2 finished, or a Status cell got typed over by hand.
A lot of purple flagsThe address pull grabbed a home address instead of the military one. Recheck the Part 2 export.
