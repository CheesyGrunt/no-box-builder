No Box / Set the password

Set the password

Type the password you want. This page turns it into a hash and gives you one line to paste into config.js. The password itself never gets saved, sent, or written into the repo.

Step 1

Pick a password

Two different passwords. The team one opens the list and is also the encryption key. The admin one is what lets someone run a new month and overwrite what staff see. Four random words beats one clever word.

Step 2

Paste this into config.js

Replace the whole window.NOBOX_CONFIG block with this, then commit. Render redeploys on its own.

config.js

    

    

      
Optional

      
Fill in owner and repo with your GitHub username and repository name so the builder can publish straight to the live site. Edit hint to whatever helps your team remember, for example "Ask Cody." Never put an actual password there.

    

    

      
What this does and does not do

      
It keeps casual visitors out. It is not encryption. Anyone determined enough can read the page source, and the hash is sitting in it. That is an acceptable trade here because the site holds no member data, only code. If the tool ever stores data, this is not the control to rely on.

    

  


  

    
Turning it off

    
Removing the password

    
Set passwordHash back to an empty pair of quotes in config.js and commit. The lock screen disappears.
